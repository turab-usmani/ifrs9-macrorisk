1. Logit Transmission Model

To prevent unbounded probabilities (> 1.0 or < 0.0), macroeconomic stress is transmitted via the log-odds (logit) transformation:

Logit = ln(PD / (1 - PD))

Stressed Logit = Logit + (βU · ΔU) + (βπ · Δπ)

Stressed PD = 1 / (1 + exp(-Stressed Logit))

2. SICR & Staging Policy

  • Stage 3: Stressed PD12m ≥ 0.20 (20% default boundary). Evaluated at 100% lifetime loss.
  • Stage 2 (SICR): Stressed PD12m / Base PD12m ≥ 2.00x. Lifetime ECL applies.
  • Stage 1: Performing facilities with stable risk profile. 12-month ECL applies.

3. Enterprise Architecture

Built with ASP.NET Core Minimal APIs (.NET 10), EF Core SQLite data access strictly enforcing .AsNoTracking() and async cancellation propagation. Sensitivities injected via IOptions<Ifrs9Settings>.
